# Decentraland Scenes

Open scenes for Decentraland, each built to learn from. Clone one, run it, and see how it works. Every scene here is MIT licensed, so you can take what you need and start your own.

## Start with thestatic.tv

Starter scenes for the [thestatic.tv scene SDK](https://www.npmjs.com/package/@thestatic-tv/dcl-sdk). Each tier adds a little more. The Standard and Pro features run on a thestatic.tv plan.

- [Free starter](https://github.com/thestatic-tv/thestatic-dcl-free): visitor tracking and session metrics.
- [Standard starter](https://github.com/thestatic-tv/thestatic-dcl-standard): a video screen, a channel guide and chat.
- [Pro starter](https://github.com/thestatic-tv/thestatic-dcl-pro): everything in Standard, plus an in-scene admin panel.

## Learn one technique

- [Curved screen](https://github.com/Metaone-Designs/dcl-curved-screen-workshop): a curved video screen built from segments in code, with a curve you can tune. From a Creator Academy workshop I hosted.
- [Multi-action animations](https://github.com/Metaone-Designs/creators-academy-ws5-animations): one model with idle, proximity and click animations, kept in order by a simple state machine.
- [Video on a model](https://github.com/Metaone-Designs/m1d-dcl-videoTexture-toGLB): play video across the surface of your own 3D model.
- [AI-assisted scene design](https://github.com/Metaone-Designs/dcl-ai-assisted-scene-design-workshop): a floating zen garden with orbiting platforms and a clickable crystal, designed with AI help.

## See it all together

- [Interactive nightclub](https://github.com/Metaone-Designs/live_fx_music_venu_dcl): a streaming screen, a pulsing dance floor, moving lights and a control panel players can use.
- [Creators Academy capstone](https://github.com/Metaone-Designs/m1d-creators-academy-capstone): the workshops combined into one world, with curved screens, the animated centerpiece, the zen garden, the nightclub and a walk-in teleporter.
